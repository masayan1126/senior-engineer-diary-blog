業務でMCPのカスタムコネクタを実装している。今日初めてカスタムコネクタを追加した時のログファイルの場所を知った。

## ログファイルの場所

カスタムコネクタを追加した時に出るエラーログはここにある。

```
/Library/Logs/Claude/claude.ai-web.log
```

エラーが出た時にどこを見ればいいかわからなかったので、これを知れたのは大きい。

## リモートじゃないとダメかもしれない

そもそもカスタムコネクタはリモートじゃないとダメな可能性がある。ローカルで動かそうとしてうまくいかない場合、ここがハマりポイントになりそう。
