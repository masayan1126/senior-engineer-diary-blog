## 何をしたか

本業のプロジェクトでClaude Codeを使ったAI駆動開発の整備を進めている。今日はissueのテンプレート作成とGitHub Projectsの機能を確認していた。

## なぜしたのか

チームでClaude Codeを活用するにあたって、issueの粒度やラベル体系がバラバラだと効率が落ちる。AIに作業を任せるなら、issueのテンプレートを統一しておく方が指示の精度が上がる。その前段階として、ラベルのパターンを先に決めておいて、そこからテンプレートを一気に揃えたかった。

## どうやってしたのか

あらかじめissueのラベルのパターン（バグ、機能追加、リファクタリングなど）を用意しておいて、Claude Codeにそのラベル体系からissueテンプレートを一括生成させた。ラベルごとにテンプレートの構成（再現手順、期待する動作、影響範囲など）を変えてくれるので、手作業で一つずつ作るよりかなり速い。

GitHub Projectsも久しぶりに触ったが、カンバンの内容をCSVエクスポートできるようになっていたり、フィルターやソート条件が充実していたりと、かなり前に使った時よりも進化していた。以前はできなかった記憶があるので、いつの間にか改善されていたようだ。

## やってみての感想

issueテンプレートの一括生成は地味に感動した。ラベルのパターンを渡すだけで、それぞれに適した構成のテンプレートをまとめて作ってくれる。こういう「定型だけど量がある作業」はClaude Codeが本当に得意なところだと改めて感じた。

GitHub Projectsの進化も嬉しい。CSVエクスポートができると、進捗の共有や報告資料の作成が楽になる。フィルター・ソートの改善も、issueが増えてきた時に効いてくるはず。開発ワークフロー全体をAI前提で整備していく中で、GitHub側のツールも着実に良くなっているのは心強い。
